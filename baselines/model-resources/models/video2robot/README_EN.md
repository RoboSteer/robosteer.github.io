# video2robot — public reference edition

**Reference only.** This directory currently provides original single-run orchestration and validation scripts. It does not include upstream project source, pretrained weights, body models or robot assets. Historical validation required external or unpublished dependencies; the current public files alone cannot reproduce the reported runs.

Download the [reference archive](video2robot_reference_20261006.zip) and verify it with its [SHA256 file](video2robot_reference_20261006.zip.sha256). Read [public scope](PUBLIC_SCOPE.md) first, then obtain upstream material from the [official project](https://github.com/AIM-Intelligence/video2robot) under its own terms. Older detailed guides document the historical workflow; commands that name excluded files are illustrative.

Archive checksums verify transfer integrity only. They do not establish installation success, motion quality, robot safety or redistribution permission.
