# TextOp — public reference edition

**Reference only.** This directory currently provides reference guides, an original checker and authorized text examples. It does not include upstream project source, pretrained weights, body models or robot assets. Historical validation required external or unpublished dependencies; the current public files alone cannot reproduce the reported runs.

Download the [reference archive](source/TextOp_reference_20261006.tar.gz) and verify it with its [SHA256 file](source/TextOp_reference_20261006.tar.gz.sha256). Read [public scope](PUBLIC_SCOPE.md) first, then obtain upstream material from the [official project](https://github.com/TeleHuman/TextOp) under its own terms. Older detailed guides document the historical workflow; commands that name excluded files are illustrative.

Archive checksums verify transfer integrity only. They do not establish installation success, motion quality, robot safety or redistribution permission.
