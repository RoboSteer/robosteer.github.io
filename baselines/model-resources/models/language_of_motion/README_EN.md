# Language of Motion — public reference edition

**Reference only.** This directory currently provides project-authored run, binding and validation tools. It does not include upstream project source, pretrained weights, body models or robot assets. Historical validation required external or unpublished dependencies; the current public files alone cannot reproduce the reported runs.

Download the [reference archive](language_of_motion_reference_20261006.zip) and verify it with its [SHA256 file](language_of_motion_reference_20261006.zip.sha256). Read [public scope](PUBLIC_SCOPE.md) first, then obtain upstream material from the [official project](https://github.com/Juzezhang/language_of_motion) under its own terms. Older detailed guides document the historical workflow; commands that name excluded files are illustrative.

Archive checksums verify transfer integrity only. They do not establish installation success, motion quality, robot safety or redistribution permission.
