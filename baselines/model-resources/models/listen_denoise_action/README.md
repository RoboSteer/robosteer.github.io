# ListenDenoiseAction — public reference edition

**Reference only.** This directory currently provides original adapters and orchestration files. It does not include upstream project source, pretrained weights, body models or robot assets. Historical validation required external or unpublished dependencies; the current public files alone cannot reproduce the reported runs.

The directory files are provided directly. Read [public scope](PUBLIC_SCOPE.md) first, then obtain upstream material from the [official project](https://github.com/simonalexanderson/ListenDenoiseAction) under its own terms. Older detailed guides document the historical workflow; commands that name excluded files are illustrative.

Archive checksums verify transfer integrity only. They do not establish installation success, motion quality, robot safety or redistribution permission.
