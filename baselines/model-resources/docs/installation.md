# Installation status / 安装状态

The current repository is a **reference edition**, not a complete executable release. Every model requires upstream source, weights or assets that are not distributed here. The detailed model guides describe historical workflows and may mention paths that exist only after separately obtaining upstream dependencies. Do not treat a checksum PASS as proof of a fresh installation.

当前仓库为**参考版**，不提供任何模型的完整可执行安装包。每个模型都需要本仓库未分发的上游源码、权重或资产。各模型详细教程记录历史流程；其中命令依赖用户另行取得的外部文件。校验通过不等于已在新机器上安装或运行。

Start with the model's `PUBLIC_SCOPE.md`, follow its official upstream links and licenses, then adapt the project-authored scripts in its archive. Use a fresh output directory for each run. No global environment or one-command installation is claimed.
