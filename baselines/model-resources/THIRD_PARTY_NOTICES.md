# Third-party sources and release limits

The current public reference edition links to upstream projects instead of redistributing their source trees, weights, body models or robot assets. In particular, the current MotionCraft archive no longer contains the Unitree G1 description and meshes that appeared in an earlier archive. Previously downloaded copies or external caches may persist after repository history cleanup.

| Project or resource | Official source | Current bundle |
| --- | --- | --- |
| GEM / GENMO | [NVlabs/GENMO](https://github.com/NVlabs/GENMO) | Linked, not copied; upstream noncommercial terms apply |
| MotionCraft | [DingyeChen/MotionCraft](https://github.com/cure-lab/MotionCraft) | Linked, not copied |
| GMR | [YanjieZe/GMR](https://github.com/YanjieZe/GMR) | Linked, not copied |
| GR00T WholeBodyControl / SONIC | [NVlabs/GR00T-WholeBodyControl](https://github.com/NVlabs/GR00T-WholeBodyControl) | Linked, not copied |
| SMPL-X | [Official model site and terms](https://smpl-x.is.tue.mpg.de/modellicense.html) | Not included |
| Other model source and weights | Links and revisions in each model directory | Not included |
